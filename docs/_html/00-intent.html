00-brief — 맥 상주 프롬프트 런처 (가칭: JARVIS Launcher)

상태: 작가님 확인 대기 (2026-10-27)

무엇을, 누구를 위해

  • 사용자: 작가님 1인 (MacBook, Orca 터미널에서 Claude Code 여러 세션 운영)
  • 문제: 여러 Orca 세션에 요청을 보내거나 새 프로젝트를 시작할 때마다 터미널을 찾아 들어가 길게 타이핑해야 함
  • 해결: 핫키 한 번으로 화면 가운데 프롬프트 창을 띄우고, 말로 요청하면 알맞은 Claude Code 세션으로 보내거나 새 프로젝트를 플랜 모드로 시작

핵심 기능 3가지

  1. 호출과 입력
    • 전역 핫키로 화면 가운데 반투명 프롬프트 창(Spotlight 느낌), 메뉴바 상주
    • 마이크 버튼으로 받아쓰기: 로컬 경량 모델 (현재 설치된 Whisper 사용 가능, 한국어 인식률 더 좋은 경량 모델 비교 후 선택 — PRD에서 결정)
    • 텍스트 직접 입력도 가능
  2. Orca 세션 연결과 라우팅
    • 설정: Orca CLI로 열린 터미널 세션 목록을 불러와 프로젝트별로 페어링
    • 앱 시작 때마다 자동 재연결 (재부팅 등으로 세션 핸들이 바뀌어도 프로젝트 기준으로 다시 짝지음)
    • 요청 내용을 보고 앱이 보낼 세션을 자동 추천 → 작가님이 확인 후 전송
  3. 새 프로젝트 시작
    • 말한 내용을 Typeless처럼 구조화된 메타 프롬프트로 정리 (확인·수정 가능)
    • 설정의 기본 상위 폴더 아래 앱이 프로젝트 이름을 제안 → 작가님 확인 → 폴더 생성
    • 새 Orca 터미널을 열고 Claude Code를 플랜 모드로 시작해 메타 프롬프트 전달
    • 시스템에 설치된 Claude Code 스킬 목록을 보여주고 골라서 호출 가능

결정 사항

  • 플랫폼: macOS 전용, Swift 네이티브 (윈도우는 범위 밖)
  • 판단 엔진(세션 추천·메타 프롬프트 정리): 로컬 경량 모델 — 오프라인, 추가 비용 없음
  • 받아쓰기: 로컬 모델
  • 호출: 첫 버전은 핫키만

제외 (다음 버전)

  • 음성 호출(웨이크 워드)
  • 윈도우판
  • 클라우드 API 사용

MVP 완료 기준 (초안)

  • 핫키로 창이 뜨고 닫힘, 메뉴바 상주
  • 한국어 받아쓰기가 창에 입력됨
  • 앱 시작 시 Orca 세션 목록을 불러와 페어링 유지
  • 기존 프로젝트 요청: 추천 세션 표시 → 확인 → 해당 Orca 터미널에 전송 성공
  • 새 프로젝트 요청: 메타 프롬프트 생성 → 폴더 이름 확인 → 새 터미널에서 Claude Code 플랜 모드로 전달 성공
  • 스킬 목록 조회·선택 가능
