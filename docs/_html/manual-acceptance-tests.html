M6 수동 확인 목록 (작가님 참여 항목 모음)

구현을 마친 뒤 M6 점검에서 한 번에 진행한다. 화면 자동화(키 이벤트 주입)는 쓰지 않는다. 기록은 진단 로그(.local-data/diagnostics.log)와 아래 집계 스크립트로 남긴다.

시작 전 결정이 필요한 것

#결정이유
D1로컬 LLM 모델: q4(제3자 Q4KM, 1.03GiB) / q8(Qwen 공식 Q8_0, 1.71GiB)docs/model-download-plan.md. AC-06·11·24의 LLM 항목이 이 결정에 달림
D2새 프로젝트 실기 테스트용 상위 폴더를 Git 밖, 프로젝트 폴더 밖에 하나 둘지(예: 작가님이 지정한 빈 폴더)지금은 '프로젝트 폴더 밖 수정 금지' 제약 때문에 Git 저장소 안 샌드박스만 쓸 수 있다. 그래서 kind: folder 등록이 미검증이다(L4)
D3마이크 '거부' 경로 확인을 위해 이 앱의 마이크 권한 초기화(tccutil reset Microphone dev.vibelabs.jarvis-launcher)를 허용할지시스템 권한 DB를 바꾸는 작업이다

작가님 확인 항목 (예상 20~30분)

준비: scripts/run-dev.sh로 실행. 테스트용 Orca 터미널은 제가 미리 만들어 두고 핸들을 알려 드린다(기존 세션에는 보내지 않음).

#AC하실 일기록·집계
101⌃⌥Space로 열고, 입력 칸 커서를 확인하고, 다시 ⌃⌥Space로 닫기 ×30python3 -I qa/scripts/ac01-tally.py
202내장 화면과 외장 화면에서 각각 열기. 다크 모드와 '대비 증가'(손쉬운 사용)를 켠 상태에서 입력해 보기진단 로그 screen=, insideVisibleFrame= + 작가님 확인 한 줄
303한/영 섞인 여러 줄과 경로를 입력하고 ⌘↵ → 뒤로 → ⌘↵를 반복해도 원문이 그대로인지 확인작가님 확인 한 줄
404·21받아쓰기 버튼을 처음 눌러 권한 허용 → 녹음. (D3 승인 시) 거부 후에도 텍스트 입력이 되는지 확인진단 로그 mic.permission, stt.done
505준비된 40문장(일반 10 / 개발용어 10 / 경로·명령 10 / 잡음 환경 10)을 받아쓰기로 읽기녹음은 저장하지 않으므로 전사 결과와 정답을 비교하는 스크립트로 집계(이 단계 전에 준비)
608설정 > 프로젝트에서 테스트 터미널을 '연결' → 앱 종료 후 재실행 → 상태가 '연결됨'인지 확인진단 로그 orca.refresh connected=
714패널에서 테스트 프로젝트로 짧은 요청 전송. 전송 버튼을 두 번 연달아 눌러 보기진단 로그 dispatch outcome= 횟수 + Orca 화면
817·18(D2 폴더에서) '새 프로젝트' → 폴더 이름 확인 → 생성 후 전달. MCP 대화상자가 뜨면 Orca에서 처리한 뒤 '여기서 이어하기'체크포인트 파일 creations.json + 진단 로그 create.*
920스킬 탭에서 테스트 스킬 선택 → 테스트 터미널로 호출진단 로그 + Orca 화면
1006(D1 다운로드 후) Wi-Fi를 끄고 받아쓰기·분류가 되는지 확인진단 로그 + lsof 점검
1125Orca 재시작, Claude 종료한 터미널로 전송 시도(차단되어야 함), 절전 후 복귀하고 핫키, 한영 전환 입력진단 로그 + 작가님 확인

  • 40문장 정답 파일과 집계 스크립트(전사 결과만 기록하고 음성은 저장하지 않음)
