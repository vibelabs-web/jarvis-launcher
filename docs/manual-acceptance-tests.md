## 작가님 확인 항목 (예상 20~30분)

준비: `scripts/run-dev.sh`로 실행. 테스트용 Orca 터미널은 제가 미리 만들어 두고 핸들을 알려 드린다(기존 세션에는 보내지 않음).

| # | AC | 하실 일 | 기록·집계 |
|---|---|---|---|
| 1 | 01 | ⌃⌥Space로 열고, 입력 칸 커서를 확인하고, 다시 ⌃⌥Space로 닫기 ×30 | `python3 -I qa/scripts/ac01-tally.py` |
| 2 | 02 | 내장 화면과 외장 화면에서 각각 열기. 다크 모드와 '대비 증가'(손쉬운 사용)를 켠 상태에서 입력해 보기 | 진단 로그 `screen=`, `insideVisibleFrame=` + 작가님 확인 한 줄 |
| 3 | 03 | 한/영 섞인 여러 줄과 경로를 입력하고 @목록 열기·닫기, 칩 바꾸기를 반복해도 원문이 그대로인지 확인 | 작가님 확인 한 줄 |
| 4 | 04·21 | 받아쓰기 버튼을 처음 눌러 권한 허용 → 녹음. (D3 승인 시) 거부 후에도 텍스트 입력이 되는지 확인 | 진단 로그 `mic.permission`, `stt.done` |
| 5 | 05 | 준비된 40문장(일반 10 / 개발용어 10 / 경로·명령 10 / 잡음 환경 10)을 받아쓰기로 읽기 | 녹음은 저장하지 않으므로 전사 결과와 정답을 비교하는 스크립트로 집계(이 단계 전에 준비) |
| 6 | 08 | `@` 목록에서 테스트 터미널을 '연결하기' → 앱 종료 후 재실행 → 다시 열었을 때 칩이 `지난 대상 · 연결됨`인지 확인 | 진단 로그 `orca.refresh connected=` |
| 7 | 14 | `@`로 테스트 프로젝트 선택 → 짧은 요청 → ⌘↵. ⌘↵를 빠르게 두 번 눌러 보기 | 진단 로그 `dispatch outcome=` 횟수 + Orca 화면 |
| 8 | 17·18 | `@` → `＋ 새 프로젝트` → 내용 입력 → ⌘↵ → 카드에서 폴더 이름 확인 → 만들고 전달. 멈추면 Orca에서 처리 후 '여기서 이어하기' | `creations.json` + 진단 로그 `create.*` |
| 9 | 20 | 입력 중 `/`로 테스트 스킬 선택 → 테스트 프로젝트로 ⌘↵ | 진단 로그 + Orca 화면 |
| 10 | 06 | (D1 다운로드 후) Wi-Fi를 끄고 받아쓰기·분류가 되는지 확인 | 진단 로그 + `lsof` 점검 |
